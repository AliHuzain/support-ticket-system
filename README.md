# Support Ticket System

[![tests](https://github.com/AliHuzain/support-ticket-system/actions/workflows/test.yml/badge.svg)](https://github.com/AliHuzain/support-ticket-system/actions/workflows/test.yml)

A REST API for support tickets, built with Python, FastAPI and SQLAlchemy on SQLite. You can create, list, filter, search, paginate, update and delete tickets. Input is validated with Pydantic, and the API tests run on every push with GitHub Actions.

## Features
- Create a ticket with a customer name, title, description and priority (Low, Medium or High; Medium by default)
- The server generates the ID (UUID), the starting status (Open) and the creation time
- List tickets newest first:
  - filter by status and priority
  - search the title and description with `q`
  - paginate with `limit` (1–100) and `offset`
- Get a single ticket, change its status (Open, In Progress, Closed) or delete it
- Clear errors: 404 for an unknown ticket, 422 for invalid input
- Interactive API docs at `/docs`, generated by FastAPI

## API
| Method | Path | What it does |
|---|---|---|
| GET | `/` | Health check |
| POST | `/tickets` | Create a ticket |
| GET | `/tickets` | List tickets (`status`, `priority`, `q`, `limit`, `offset`) |
| GET | `/tickets/{ticket_id}` | Get one ticket |
| PATCH | `/tickets/{ticket_id}/status` | Change a ticket's status |
| DELETE | `/tickets/{ticket_id}` | Delete a ticket |

Example:
```bash
curl -X POST http://127.0.0.1:8000/tickets \
  -H "Content-Type: application/json" \
  -d '{"customer_name": "Sara", "title": "Login issue", "description": "Cannot log in after a password reset", "priority": "High"}'
```

## Run it
```bash
pip install -r requirements.txt
uvicorn app.api:app --reload
```
Then open http://127.0.0.1:8000/docs. Tickets are stored in `tickets.db` (SQLite), which is created on first start.

## Tests
```bash
python -m pytest
```
The same tests run in GitHub Actions on every push and pull request to `main`.

## Project structure
- `app/api.py`: FastAPI routes
- `app/storage.py`: database queries (create, list, count, update, delete)
- `app/models.py`: request and response schemas (Pydantic)
- `app/db_models.py`, `app/db.py`: the SQLAlchemy table and the SQLite connection
- `tests/test_api.py`: API tests
- `app/main.py`, `app/tickets.py`: the original console demo of a `Ticket` class (`python app/main.py`)
